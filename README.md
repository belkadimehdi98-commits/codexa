\# Codexa 🚀



Codexa is an \*\*AI-powered coding assistant\*\* that helps you \*\*chat, generate code, create images, and learn with tutorials\*\* — all in one platform.



🔗 Live site: \[codexa.codes](https://codexa.codes)



---



\## ✨ Features

\- 💬 \*\*AI Chat\*\* — natural conversations with Codexa  

\- 💻 \*\*Code Generation Mode\*\* — instant coding snippets with \*\*Copy\*\* \& \*\*Download\*\*  

\- 🖼️ \*\*Image Generation Mode\*\* — create visuals directly from your prompts  

\- 📘 \*\*AI Tutorials\*\* — step-by-step coding lessons generated on demand  

\- 💳 \*\*Stripe Integration\*\* — Free, Pro, and Team plans (subscription-ready)  

\- 📱 \*\*Responsive Design\*\* — optimized for desktop and mobile
