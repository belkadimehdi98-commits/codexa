🚀 Welcome to Codexa!

This step-by-step guide will help you go from AI-generated code to a working website in just a few minutes.

Step 1: Generate Your Code

In the AI Generator, type your idea (e.g., “A landing page for my startup”). Once ready, click Generate Code.

Step 2: Copy or Download

You’ll see your generated code appear. - Click Copy to copy it to your clipboard. - Or click Download to save it as index.html.

Step 3: Run Your Website Locally

  1. Open a code editor like VS Code.
  2. Paste your code into a new file and save it as index.html.
  3. Double-click index.html → it opens in your browser!

Step 4: Host Online 🌍

You can easily publish your site online for free:

  • Netlify → drag & drop your index.html
  • Vercel → connect GitHub & deploy
  • GitHub Pages

Step 5: Customize ✨

Open index.html in your editor and start editing text, colors, or styles. You can add images, links, or even your own JavaScript.
