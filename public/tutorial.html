📖 Codexa Tutorial

Learn how to turn your AI-generated code into a live website

Step 1: Generate Your Code

Go to the AI Generator, describe your idea, and click Get Your Code Now. Copy or download the result.

Step 2: Open a Code Editor

We recommend Visual Studio Code. Create a new file and paste your code inside.

Step 3: Save Your File

Save your file as index.html. Make sure the file extension is .html, not .txt.

Step 4: Open in Browser

Double-click index.html. Your browser will open your new website instantly 🎉

Step 5: Publish Online

Want to share with the world? Upload your file to free hosting platforms:

  • Vercel
  • Netlify
  • GitHub Pages

Pro Tips

  • Edit your code in VS Code and refresh the browser to see changes.
  • Use free themes/templates generated by Codexa for faster results.
  • Upgrade your plan for unlimited generations and team access.
