How to Use Codexa

Step 1 – Generate Code

Start a chat with AI. When you’re ready, click 💻 Generate Code. Your code will appear inside the chat with copy/download options.

Step 2 – Open Locally

1. Copy/download your code.
2. Open VS Code.
3. Paste the code into a new file and save as index.html.
4. Double-click index.html → your site opens in browser.

Step 3 – Host Online

Upload your index.html to a free host:

  • Netlify
  • Vercel
  • GitHub Pages
